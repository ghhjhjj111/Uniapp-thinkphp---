UniApp 点餐外卖小程序源码（ThinkPHP 餐饮系统）开源搭建教程
一、方案概述
UniApp + ThinkPHP 是国内餐饮点餐外卖小程序最主流的技术组合之一。UniApp 负责用户端多端适配（微信小程序、H5、App），ThinkPHP 负责后端 API 与业务逻辑。二者配合，可实现扫码点餐、外卖下单、后厨打印、商家管理等完整闭环，且源码开源、部署简单、成本可控，非常适合中小餐饮商户、创业团队与毕业设计项目。

二、源码获取渠道
开源社区：GitHub、Gitee 搜索“ThinkPHP 点餐”“UniApp 外卖”“扫码点餐 开源”等关键词，可找到不少 MIT/Apache 协议项目，适合学习与二次开发。

源码平台：码云市场、CSDN、掘金、淘宝等有大量付费源码，价格从几百到数千元，通常附带部署文档与数据库脚本。

商业 SaaS：客如云、哗啦啦等按年收费，不提供源码，稳定性高但数据不在自己手中。

选源码重点：确认 PHP 版本（7.4+）、ThinkPHP 版本（6.0+）、数据库脚本完整、支付与打印已对接、未加密、协议允许商用、有售后支持。

三、系统架构
整体采用前后端分离：

text
用户端（UniApp 小程序/H5/App）
        ↓ HTTPS
后端 API（ThinkPHP 6）
        ↓
MySQL + Redis + OSS
        ↓
管理后台（Vue3 + Element Plus）
        ↓
商家端 / 后厨端
技术栈：后端 ThinkPHP 6 + MySQL 5.7+ + Redis；前端 UniApp + Vue2/Vue3；管理后台 Vue3 + Element Plus；支付微信支付 V3；打印飞鹅/易联云；存储阿里云 OSS/腾讯云 COS；部署宝塔 + Nginx。

四、核心功能模块
用户端：微信授权登录、扫码识桌、菜品分类与规格、购物车、下单支付、订单查询、加菜催单、评价。

商家端：菜品管理、订单接单、桌台管理、桌码生成、营业统计、打印机配置、优惠券。

后厨端：订单实时推送、小票打印、制作状态更新。

管理后台：用户管理、订单管理、财务结算、多商户管理、营销配置、系统设置。

五、搭建教程
第一步：环境准备
云服务器 2核4G 起，安装宝塔面板，配置 Nginx、PHP 7.4+、MySQL 5.7+、Redis，申请 SSL 证书，完成域名备案。

第二步：后端部署
上传 ThinkPHP 代码，设置运行目录为 public，配置伪静态：

nginx
location / {
    if (!-e $request_filename) {
        rewrite ^(.*)$ /index.php?s=$1 last;
    }
}
导入数据库脚本，修改 .env 中的数据库、Redis、支付、打印参数。

第三步：前端编译
用 HBuilderX 打开 UniApp 项目，修改 utils/request.js 中的 API 地址，编译到微信小程序，用微信开发者工具上传审核；H5 打包后放 Nginx 静态目录；App 云打包生成安装包。

第四步：配置与联调
微信后台配置服务器域名白名单；配置支付回调地址（需公网可访问）；对接云打印机；测试扫码、下单、支付、打印、退款全流程。

第五步：上线运营
提交小程序审核（餐饮类目需食品经营许可证）；配置隐私政策；接入会员、优惠券、分销等营销模块；持续迭代。

六、关键技术难点
多人点餐：同桌多顾客扫码共享购物车，用 Redis 以桌台为 key 存储。

订单并发：Redis 原子扣库存，订单号唯一索引防重，支付回调幂等。

打印可靠：打印任务进队列，失败重试，状态回写，支持多打印机分流。

支付对接：微信支付 V3 验签解密，回调地址公网可访问，处理重复通知。

七、避坑提醒
支付资质需企业自行申请；多商户分账涉及资金合规，建议走微信服务商模式；小程序审核需食品经营许可证；低价源码常见缺文档、支付写死、无法升级；高并发务必处理订单锁与库存扣减。

八、总结
UniApp + ThinkPHP 是餐饮点餐外卖小程序的高性价比方案。选源码看协议、完整度与代码质量；部署重支付、打印与并发；运营逐步扩展会员、营销与多商户。按本文流程执行，可快速搭建一套可商用的点餐外卖系统。
